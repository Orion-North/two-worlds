# Two Worlds

A minimal launcher for two Space Apps games:

- [Ghost Rovers](https://scarlettkcl-beep.github.io/ghost-rover/)
- [Last Light](https://orion-north.github.io/last-light/)

Static HTML and CSS. GitHub Pages publishes the root of `main`.

Game screenshots are from the respective projects. Last Light's rover model is credited to NASA/JPL-Caltech; its surface textures are credited to Poly Haven in the game's asset ledger.
